How PulseNet works

The browser downloads and uploads controlled byte streams over HTTPS, measures elapsed time with the browser Performance API, and calculates approximate throughput. Latency is measured against the same test service. Browser tests are affected by Wi-Fi signal, device load, VPNs, browser limits and the selected test endpoint.

  • No login or password is required.
  • History stays in localStorage on this device.
  • IP/ISP enrichment is optional and can be blocked by privacy tools.
  • Results are estimates, not a guarantee of your ISP's advertised speed.
